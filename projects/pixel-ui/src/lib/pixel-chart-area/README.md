# pixel-chart-area

Area chart facade (overlay, stacked, 100% stacked) over the shared ECharts host.

> Import from `pixel-ui/charts`. Requires optional peer `echarts`.

## Overview

`pixel-chart-area` shows magnitude with area fill. Uses ECharts line series + `areaStyle`
(same modular register as line). **Streamgraph** is Phase 2 — not available yet.

## Use cases

- Overlay trends with translucent fills
- Stacked / 100% stacked part-to-whole over time

## Behavior notes

- Registers via `ensureAreaChart()` → `ensureLineChart()`.
- For unfilled lines, use `pixel-chart-line`.
- Pair with `pixel-chart-shell` for legend / table / export.

## Accessibility

Plot `role="img"` + `ariaLabel` / live summary. Prefer shell data table for keyboard access.

## Breaking changes

None (experimental).
