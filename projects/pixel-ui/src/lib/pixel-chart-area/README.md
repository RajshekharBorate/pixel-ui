# pixel-chart-area

Area chart facade (overlay, stacked, 100% stacked, experimental streamgraph) over the
shared ECharts host.

> Import from `pixel-ui/charts`. Requires optional peer `echarts`.

## Overview

`pixel-chart-area` shows magnitude with area fill. Uses ECharts line series + `areaStyle`
for overlay/stacked/percent. `mode="stream"` is a **centered stacked streamgraph**
(baseline at −Σ/2) — same line modules, no ThemeRiver.

## Use cases

- Overlay trends with translucent fills
- Stacked / 100% stacked part-to-whole over time
- Streamgraph composition over categories (experimental)

## Behavior notes

- Registers via `ensureAreaChart()` → `ensureLineChart()`.
- For unfilled lines, use `pixel-chart-line`.
- Pair with `pixel-chart-shell` for legend / table / export.
- Optional `xAxisName` / `yAxisName` and `valueSuffix` (e.g. `K` → `85K`; ignored in percent).
- Axis titles use the same on-surface color / font family as tick labels.
- Stream mode inserts a silent baseline series (`__stream-baseline`) so layers
  center on zero; legend still comes from the shell `series` input.
- When stream `showValues` is on, labels and markers appear at the **last** category only
  (end-of-flow callouts), not along the full path.

## Accessibility

Plot `role="img"` + `ariaLabel` / live summary. Prefer shell data table for keyboard access.

## Breaking changes

- Removed `brush` input and `brushEnd` output. Use `dataZoom` for range navigation.
