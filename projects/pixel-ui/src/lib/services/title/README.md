# Pixel Title

Headless **document-title** helper. Angular already ships `Title` (`@angular/platform-browser`); this service
adds product rules on top — brand prefix/suffix, unread count, truncation, sanitization,
error titles, and an opt-in `TitleStrategy` — without wrapping `Title` as a no-op.

> **Docs IA:** registered under the **Services** category (`pixel-title`) — headless,
> not a `pixel-*` UI folder (CONVENTIONS §3e).

This is **not** an SEO / Open Graph helper (`Meta`, `og:title`, canonical, robots). Apps
that need share cards own `@angular/platform-browser` `Meta` themselves.

## Overview

- `PixelTitleService.set()` writes `document.title` **only** through Angular `Title` (SSR-safe)
- Config: `prefix`, `suffix`, `separator` (` · `), `maxLength` (60), `defaultTitle`, labels
- Parts: `{ page, section?, count? }` → `(3) Inbox · Security · Acme`
- Truncate **page** first; keep brand when it still fits
- Count-only updates debounce (~1s) so tabs do not flicker
- Opt-in `syncRouterTitle` installs **one** writer (`PixelTitleStrategy`) — do not also keep
  `DefaultTitleStrategy` or a `NavigationEnd` subscriber that sets the title
- Nested routes: **leaf** primary-outlet title (Angular `buildTitle`); named outlets ignored
- Dialogs / drawers must **not** change the title

## Use cases

- App-wide `Policies · Acme` suffix without copy-paste
- Inbox unread badge in the browser tab
- 404 / 403 titles from `setError()`
- Shared formatter across apps / micro-frontends
- Route `title:` values composed with the same brand rules

## Setup

```ts
import { providePixelTitle } from 'pixel-ui';

export const appConfig: ApplicationConfig = {
  providers: [
    provideRouter(routes),
    providePixelTitle({
      suffix: 'Acme',
      defaultTitle: 'Home',
      syncRouterTitle: true, // optional — route title is the single writer
    }),
  ],
};
```

`PixelTitleService` is `providedIn: 'root'`. `providePixelTitle()` is only required to
override defaults or opt into router sync. `suffix` / `prefix` are brand strings **without**
the separator (`'Acme'`, not `' · Acme'`).

Route titles (leaf wins; ancestor used when the leaf omits `title`):

```ts
export const routes: Routes = [
  { path: 'inbox', component: InboxPage, title: 'Inbox' },
  {
    path: 'settings',
    title: 'Settings',
    children: [{ path: 'security', component: SecurityPage, title: 'Security' }],
  },
];
// /settings/security → "Security · Acme"
```

## Usage

```ts
private readonly titles = inject(PixelTitleService);

titles.set('Policies');
// document.title → "Policies · Acme"

titles.set({ page: 'Inbox', count: 3 });
// "(3) Inbox · Acme"

titles.set({ page: 'Inbox', section: 'Security', count: 3 });
// "(3) Inbox · Security · Acme"

titles.setError('not-found');
// "Page not found · Acme"

titles.fromTrail(breadcrumb.items());
// last crumb label as page — only when you are not already syncing route titles

titles.reset();
// defaultTitle · suffix
```

Stale async (ignore a write if the user already navigated away):

```ts
const navigationId = inject(Router).lastSuccessfulNavigation?.id;
this.entity$.subscribe((entity) => {
  this.titles.set(entity.name, { navigationId });
});
```

### Service `PixelTitleService`

Formats and writes `document.title` through Angular `Title`. Adds product rules Angular does not: brand prefix/suffix, unread count, truncation, sanitization, and an opt-in `PixelTitleStrategy` for route titles. This is **not** a Meta / Open Graph helper (SEO is out of scope). Dialogs and drawers must not call `set` — overlays are not navigations.

| Method | Signature | Description |
| --- | --- | --- |
| `set` | `set(input: string | PixelTitleParts, options?: PixelTitleSetOptions): void` | Replace the document title. A string is treated as `page`. Each call replaces parts (it does not merge with the previous `count` / `section`). Count-only updates are debounced; every other change is last-write-wins immediately. |
| `reset` | `reset(options?: PixelTitleSetOptions): void` | Restore `defaultTitle` (plus prefix / suffix). |
| `setError` | `setError(kind: PixelTitleErrorKind, options?: PixelTitleSetOptions): void` | Apply a localized error title (`not-found` / `forbidden` / `error`). Does not change the URL; pair with the app's error route. |
| `fromTrail` | `fromTrail(items: readonly Pick<PixelBreadcrumbItem, 'label'>[] | null | undefined, options?: PixelTitleSetOptions): void` | Use the last breadcrumb label as `page`. Route `title` (via `PixelTitleStrategy`) wins unless the app calls this explicitly instead. |
| `setFromRouteTitle` | `setFromRouteTitle(title: string | null | undefined): void` | Used by `PixelTitleStrategy` after a successful navigation (leaf primary route title). Missing titles reset to `defaultTitle`. Cancels a pending count debounce. |

### Service `PixelTitleStrategy`

Single writer for route titles. Angular's `TitleStrategy.buildTitle` walks the **primary** outlet and keeps the deepest defined `title` (leaf, else ancestor). Named / auxiliary outlets are ignored. Provided only when `providePixelTitle` is called with `syncRouterTitle: true`. Do not register this class **and** keep `DefaultTitleStrategy` or a Router `NavigationEnd` subscriber that also writes the title.

## Behavior notes

- **One writer.** `syncRouterTitle: true` is the supported way to compose route titles. Subscribing to `Router` events **and** leaving `DefaultTitleStrategy` in place double-sets the title (last writer wins, suffix may flicker off).
- **Leaf only.** Nested routes use Angular `TitleStrategy.buildTitle` (deepest primary `title`, else the nearest ancestor). This service does not join `child · parent · brand`.
- **Route title vs breadcrumb.** `PixelTitleStrategy` uses route `title`. `fromTrail()` is explicit. Do not call `fromTrail()` on every `NavigationEnd` when router sync is on — the route title wins unless you skip `syncRouterTitle` and drive titles from the trail yourself.
- **Count debounce.** Updating `count` while `page` / `section` stay the same waits `countDebounceMs` (default 1s). A page change flushes immediately and cancels the timer. `count ≤ 0` is omitted. Counts are **tab UX**, not a second SEO string (no `seoTitle` / `og:title` split in this version).
- **Truncation.** Default `maxLength` is 60. The page is shortened with `…` first; `section` is dropped next; brand prefix/suffix stay if they still fit. A custom `format` function is clipped as a whole.
- **Sanitize.** Naive HTML tags stripped; newlines/tabs become spaces; remaining C0/C1 controls removed; whitespace collapsed. `Title` does not HTML-parse; still treat the string as text. Never put PII, tokens, or account numbers in the title (screenshots, shoulder surfing).
- **Query / hash.** Do not put `?q=` / page index / filters in the title.
- **Overlays.** `pixel-dialog` and `pixel-drawer` must not call this service. They are not a new URL; assistive tech already gets the dialog name.
- **Loading / back-forward.** `PixelTitleStrategy.updateTitle` runs after a successful navigation, so the previous title stays during in-flight routing. History back/forward re-runs the strategy. Prefer router sync over `ngOnDestroy` + `reset()` on feature components.
- **Rapid `set()`.** Last write wins. Pass `navigationId` to drop stale async work.
- **Multi-tab / iframe.** Each document has its own title. This service does not sync across tabs. Inside an iframe, `Title` updates the iframe document, not the parent.
- **SSR.** No `window` / `document` access except through Angular `Title`.
- **i18n.** Pass localized `labels` and `suffix` from the app. `document.documentElement.lang` is owned by the app, not this helper.
- **a11y.** Many AT announce the new title on route change. Do not also push the same string into an `aria-live` region. Empty titles are warned in dev because they skip that announcement.
- **Dev warnings.** Empty page (and no `defaultTitle`); composed string longer than `maxLength` before truncation.
- **Default Angular.** Apps that only need `Routes.title` can skip this helper entirely.

## Examples

```ts
providePixelTitle({ suffix: 'Acme', syncRouterTitle: true });

titles.set({ page: 'Inbox', count: unread() });
titles.setError('forbidden');
```

## Accessibility

- Route changes that update `document.title` are announced by many screen readers — keep titles unique enough to notice, and avoid count flicker (debounce).
- Do not duplicate the title in a live region.
- Error pages should call `setError` (or set a route `title`) so the tab is not still the previous page.
