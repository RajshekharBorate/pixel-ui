# pixel-button-group

Joined row (or column) of `pixel-button` actions with shared border chrome. Projects
`pixel-button` children; does **not** manage exclusive selection — use `pixel-toggle`
`mode="segmented"` for that.

## Use cases

- Toolbar action clusters (Day / Week / Month views without exclusive selection semantics)
- Paired outline actions (Cancel / Confirm) with collapsed borders
- Full-width stacked mobile action strips (`orientation="vertical"`)

## Behavior notes

- Host is `role="group"`. Prefer `ariaLabel` when there is no visible legend.
- Children keep their own `size` / `appearance` / `disabled` / `(click)` bindings; the group
  only joins borders via CSS.
- `disabled` on the group sets `pointer-events: none` and `aria-disabled` — also disable
  children for correct per-button ARIA.

## Examples

```html
<pixel-button-group appearance="outline" size="md" ariaLabel="View range">
  <pixel-button appearance="outline">Day</pixel-button>
  <pixel-button appearance="outline">Week</pixel-button>
  <pixel-button appearance="outline">Month</pixel-button>
</pixel-button-group>
```

## Accessibility

- `role="group"` + optional `aria-label`
- Each child remains a native button with its own accessible name

## Theme customization

Uses `--pixel-button-*` tokens from `_pixel-button-shared.scss` for radius and outline width.

## Breaking changes

None. New component.
