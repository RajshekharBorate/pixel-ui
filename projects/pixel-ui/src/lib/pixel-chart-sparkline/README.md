# pixel-chart-sparkline

Tiny inline trend chart rendered as **custom SVG** — **no ECharts** dependency.

## Overview

Use sparklines in dense UIs (tables, KPI strips, list rows) where a full
`pixel-chart-line` host would be too heavy. Phase 3 evaluated a tiny ECharts
subset vs SVG; SVG wins on weight (~0 ECharts KB) and SSR simplicity.

## Use cases

- KPI delta spark next to a metric
- Per-row trend in a data grid / table cell
- Compact dashboard strip without chart chrome

## Behavior notes

- `values` may include `null` gaps (skipped in the path).
- Auto `aria-label` summarizes direction and first/last when `ariaLabel` is empty.
- Tokens: `--pixel-chart-sparkline-color`, `--pixel-chart-sparkline-fill`,
  `--pixel-chart-sparkline-stroke-width`.
- Not a substitute for interactive charts — no zoom, tooltip, or legend.

## Accessibility

`role="img"` + accessible name. Prefer an explicit `ariaLabel` describing the metric.

## Theme customization

| Token | Role |
|-------|------|
| `--pixel-chart-sparkline-color` | Stroke (defaults from tone / primary) |
| `--pixel-chart-sparkline-fill` | Area fill |
| `--pixel-chart-sparkline-stroke-width` | Stroke width |
