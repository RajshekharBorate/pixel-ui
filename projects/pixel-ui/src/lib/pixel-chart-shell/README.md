# pixel-chart-shell

Dashboard card chrome for Pixel charts (title, actions, legend, data table, states).

> Import from `pixel-ui/charts`.

## Overview

Wraps a projected plot (`pixel-chart-bar`, …) with the enterprise card pattern from the
chart UX mockups. Handles legend visibility, PNG/CSV export hooks, fullscreen expand,
loading / skeleton / empty states.

## Use cases

- Dashboard chart cards
- Accessible table companion to canvas charts
- Shared export / expand actions across chart types

## Behavior notes

- **Expand** uses the Fullscreen API on the shell host (Escape exits). Dialog-based expand
  is deferred (projection cannot be cloned into `pixel-dialog` without re-binding inputs).
- **PNG** requires `getChart` → plot `getChart()` (see docs examples).
- **SVG** re-renders the live option with a temporary SVG renderer → `exportChartSvg` / shell menu.
- **CSV** uses `PixelExportService.exportTable`.
- Legend keeps at least one series visible.
- Empty state defaults from shell `series` / table rows. Plots without shell series
  (e.g. `pixel-chart-gauge`) must set `[empty]="false"` so content is projected.
- Container query (`pixel-chart-shell`) stacks the header on narrow cards; viewport
  `breakpoint-down(sm)` tightens padding.

## Accessibility

- Legend items are buttons with `aria-pressed`.
- Table has a caption; hide/show via More menu.
- Icon actions expose `aria-label`; hit targets ≥ 44×44px.

Dashboard card chrome around a chart plot: title, actions, legend, optional data table, loading / skeleton / empty states. Project the plot (`pixel-chart-bar`, …) into the default slot. Pass `getChart` so PNG export can reach the ECharts instance.
