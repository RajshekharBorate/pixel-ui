# pixel-chart-scatter

Scatter facade with optional OLS trendline.

> Import from `pixel-ui/charts`. Requires optional peer `echarts`.

## Overview

Correlation / distribution plots from `PixelChartPoint` `{ x, y }` data. Compose with
`pixel-chart-shell` for legend, table (`buildScatterTable`), and PNG/SVG export.

## Use cases

- Correlation exploration
- Multi-series overlays
- Trendline analysis

## Behavior notes

- Registers `ensureScatterChart()` (scatter + line for trend).
- Pair with shell `[(showValues)]` for point labels (prefer point `label`, else y). `auto`
  hides labels when the cloud is dense; hover still reveals values.
- Trendline is a dashed helper series (`__trendline`), not a legend item from shell series.
- `buildScatterStats()` / `computeScatterStats()` remain available as data utilities, but
  the facade no longer renders an n / r / R² footer.

## Accessibility

- Host `role="img"`; prefer `ariaLabel`.
- Pair with shell CSV export for keyboard-accessible data.

## Breaking changes

- Removed `brush` input and `brushEnd` output. Use `dataZoom` for range navigation.
- Removed `showStats` and the visual n / r / R² footer. Use the exported scatter-statistics
  utilities when an application needs to present those values elsewhere.
