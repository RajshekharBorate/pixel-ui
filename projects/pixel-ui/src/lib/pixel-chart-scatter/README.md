# pixel-chart-scatter

Scatter facade with optional OLS trendline and Pearson **r** / **R²** stats footer.

> Import from `pixel-ui/charts`. Requires optional peer `echarts`.

## Overview

Correlation / distribution plots from `PixelChartPoint` `{ x, y }` data. Compose with
`pixel-chart-shell` for legend, table (`buildScatterTable`), and PNG/SVG export.

## Use cases

- Correlation exploration
- Multi-series overlays
- Trendline + stats callouts

## Behavior notes

- Registers `ensureScatterChart()` (scatter + line for trend).
- `showStats` footer uses OLS / Pearson; sets larger than `PIXEL_CHART_STATS_MAX_N` (5000)
  are subsampled for the fit (full `n` still reported).
- Trendline is a dashed helper series (`__trendline`), not a legend item from shell series.

## Accessibility

- Host `role="img"`; prefer `ariaLabel`.
- Stats footer is labeled; pair with shell table for keyboard access.

## Breaking changes

- Removed `brush` input and `brushEnd` output. Use `dataZoom` for range navigation.
