# pixel-split-button

Primary action plus a caret that opens a `pixel-menu`. Composes `pixel-button` +
`[pixelMenuTriggerFor]` — do not use for exclusive segmented selection (`pixel-toggle`).

## Use cases

- Save / Save as… / Save and close
- Export with format choices in a menu
- Compose with optional default action and overflow options

## Behavior notes

- Bind `[menu]` to a sibling `<pixel-menu #ref>`.
- Primary `(click)` fires only for the main segment; caret opens the menu.
- Loading/disabled on the host disables both segments.
- Caret uses `menuAriaLabel` (default “More options”) and `menuIcon` (default `expand_more`).
- Segments share one continuous border with an inset divider; caret is a square hit target.

## Examples

```html
<pixel-split-button [menu]="saveMenu" (click)="save()">Save</pixel-split-button>
<pixel-menu #saveMenu ariaLabel="Save options">
  <pixel-menu-item (selected)="saveAs()">Save as…</pixel-menu-item>
  <pixel-menu-item (selected)="saveClose()">Save and close</pixel-menu-item>
</pixel-menu>
```

## Accessibility

- Host `role="group"`; caret is an icon button with `aria-haspopup="menu"`.
- Menu focus trap / Escape / restore focus come from `pixel-menu`.

## Theme customization

Joins borders via `--pixel-button-radius` / `--pixel-button-outline-width`.

## Breaking changes

None. New component.
