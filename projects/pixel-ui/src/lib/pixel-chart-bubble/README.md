# pixel-chart-bubble

Cartesian bubble chart (x / y / size) with optional paginated data table.

> Import from `pixel-ui/charts`. Requires optional peer `echarts`.

## Overview

Each point encodes magnitude via `size`. Packed / hierarchical layout is Phase 2
(`layout="pack"`).

## Use cases

- Market / portfolio bubbles
- Multi-series size comparisons
- Tabular drill-down with paginator

## Behavior notes

- Registers `ensureBubbleChart()`.
- Built-in table uses `pixel-paginator` + **View all** / **Paginate** toggle.
- Shell: `[series]="bubble.legendSeries()"`, often `[showTable]="false"` to avoid a
  second table; set `[empty]="false"` only if not passing series.

## Accessibility

- Host `role="img"`; table caption for point rows.
- Prefer explicit `ariaLabel`.

## Breaking changes

None (experimental).
